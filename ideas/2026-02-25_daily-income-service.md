# 毎日500〜1,000円稼げるオンラインサービス ブレスト

> 月換算: 15,000〜30,000円 / 年換算: 180,000〜360,000円

## 評価基準

| 基準 | 説明 |
|------|------|
| 構築難易度 | 1人で作れるか、どのくらいかかるか |
| 収益安定性 | 毎日コンスタントに稼げるか |
| 運用コスト | サーバー代・維持の手間 |
| 競合優位性 | 差別化できるポイントがあるか |
| スケール性 | 将来的に収益を伸ばせるか |

---

## アイデア一覧

### 1. AI文章リライト/校正ツール（日本語特化）

**概要**: 日本語の文章を入力すると、ビジネス文・カジュアル・敬語などに変換するWebツール

**収益モデル**: フリーミアム（1日3回無料、以降は月額500円 or 従量課金）

| 基準 | 評価 | メモ |
|------|------|------|
| 構築難易度 | ★★☆ | Flask + LLM API で基本形は1-2日 |
| 収益安定性 | ★★☆ | ユーザー獲得が鍵 |
| 運用コスト | ★★☆ | LLM API費用が発生 |
| 競合優位性 | ★☆☆ | ChatGPTで代替可能 |
| スケール性 | ★★★ | ニッチ特化で差別化余地あり |

**差別化案**: 「就活ES特化」「議事録要約特化」など狭いニッチに絞る

---

### 2. シンプルSaaSツール（画像変換/PDF操作）

**概要**: 画像リサイズ・フォーマット変換・PDF結合/分割などの単機能ツール

**収益モデル**: 広告 + プレミアム（高解像度・一括処理は有料）

| 基準 | 評価 | メモ |
|------|------|------|
| 構築難易度 | ★☆☆ | Pillow/PyPDF2で比較的簡単 |
| 収益安定性 | ★★★ | 検索流入で安定しやすい |
| 運用コスト | ★☆☆ | サーバー代のみ |
| 競合優位性 | ★☆☆ | 既存サービス多数 |
| スケール性 | ★★☆ | 複数ツールを束ねて回遊させる |

**差別化案**: 「日本語UI」「ファイルをサーバーに保存しない（プライバシー重視）」

---

### 3. 日報/週報AI自動生成ツール

**概要**: Slack/Teams/GitHubの活動ログから自動で日報・週報を生成

**収益モデル**: 月額980円〜/ユーザー（B2B SaaS）

| 基準 | 評価 | メモ |
|------|------|------|
| 構築難易度 | ★★★ | API連携が複数必要 |
| 収益安定性 | ★★★ | B2Bは解約率低い |
| 運用コスト | ★★☆ | LLM API + サーバー |
| 競合優位性 | ★★☆ | 日本の「日報文化」にフィット |
| スケール性 | ★★★ | 法人契約で一気に伸びる可能性 |

**差別化案**: 日本企業の日報フォーマットに完全対応、上司へのCC自動送信

| 基準 | 評価 | メモ |

| 収益安定性 | ★★★ | 一度導入されると継続利用 |
| 運用コスト | ★☆☆ | 軽量サーバーで十分 |

| スケール性 | ★★☆ | 顧客ごとにカスタム対応が必要になりがち |

**差別化案**: 「個人店舗向け月額500円」の激安路線、テンプレートbot量産

## 個人的おすすめ組み合わせ

```
  → シンプルSaaSツール（#2）or LINEbot（#4）

長期（1ヶ月〜）:

  → B2B路線で単価アップ
```
