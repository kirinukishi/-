# マイクロサービス・ポートフォリオ戦略

## コンセプト

> **1つ1〜3万円/月 × 10〜20個 = 月10〜60万円のストック収入**

1つの大きなサービスに賭けるのではなく、小さなサービスを量産して
ポートフォリオとして積み上げる。1つ失敗しても全体は揺るがない。

```
目標ポートフォリオ例:
┌─────────────────────────────────────────────────┐
│  月1万円級 × 10個 = 10万円  ← まずここを目指す  │
│  月2万円級 ×  5個 = 10万円  ← 当たりを伸ばす    │
│  月3万円級 ×  3個 =  9万円  ← B2B化で単価UP     │
│─────────────────────────────────────────────────│
│  合計: 約30万円/月（18個のサービス）              │
└─────────────────────────────────────────────────┘
```

## この戦略で重要な3条件

| 条件 | 理由 |
|------|------|
| **1〜3日で構築** | 量産するには1つに時間をかけすぎない |
| **手離れが良い** | 20個を同時運用するには放置で回る必要がある |
| **同じパターンで量産可** | 技術スタック・デプロイを統一して効率化 |

## 評価基準

| 基準 | 説明 |
|------|------|
| 構築速度 | 何日でMVPを出せるか |
| 手離れ度 | デプロイ後にどれだけ放置できるか |
| 量産性 | 同じパターンでバリエーションを作れるか |
| 月収見込み | 現実的に1〜3万円/月に到達できるか |
| 運用コスト | サーバー代・API費用などの固定費 |

## 推奨ロードマップ

```
Phase 1: 基盤づくり（1-2週間）
  ├── 共通テンプレート作成（Flask/Next.js）
  ├── デプロイパイプライン構築（Vercel or Fly.io）
  ├── 広告/決済の仕組みを1つ目で確立
  └── 目標: 最初の1サービスをリリース

Phase 2: 量産期（1-2ヶ月）
  ├── 週2-3個のペースでWebツールをリリース
  ├── 並行してテンプレート商品を月2個ずつ追加
  ├── SEO記事をZenn/Qiitaに投稿して流入確保
  └── 目標: 10サービス稼働、月3-5万円

Phase 3: 最適化（3ヶ月目〜）
  ├── アクセス解析で当たりサービスを特定
  ├── 当たりに機能追加 → プレミアム化で単価UP
  ├── ハズレは放置 or 畳む
  ├── データAPI系を追加（単価高いため）
  └── 目標: 15-20サービス稼働、月10-15万円

Phase 4: 拡大（6ヶ月目〜）
  ├── 月10万円超えのサービスがあればB2B化
  ├── テンプレ販売の認知が上がり始める
  ├── ポートフォリオ全体で月20-30万円を目指す
  └── 目標: 安定したストック収入の確立
```
