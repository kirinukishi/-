# Excalidraw MCP + Obsidian CLI 対応

ソース: https://www.youtube.com/watch?v=HDR4Nd9VUoo

## Excalidraw 公式MCP統合

### 何ができる
- テキストから図が自動生成される
- 「APIからキューに流してワーカーが処理する」→ 箱と矢印の構成図になる
- Claude Desktop / Claude Code から直接利用可能

### 使い方のコツ
1. **図の目的を明確にする** — 誰に何を判断させるための図か
2. **要素の数を先に固定** — 5つまでなど
3. **例外と前提を一文で添える**
4. **出力後に境界を人間が確認** — 権限の境界、ネットワークの境界、責務の境界、矢印の向き

### 注意
- 「それっぽく整う」が中身が合っているかは別問題
- 特にデータの流れ（矢印の向き）が逆になっていることがある
- **境界だけは人間が確認する**

## Obsidian 1.12 CLI対応

### 何が変わる
- コマンドラインからVaultを直接操作できる
- Claude Code / OpenCode / Codex などから連携可能
- メモが「書き溜め」→「運用資産」に変わる

### できること
- 会議メモをテンプレで新規作成
- タグ付け、関連ノートへのリンク
- Vault内検索→要約→意思決定ログに追記
- 日報、週報、プロジェクト振り返りの自動化

### 導入前に決めること
1. 個人Vaultには秘密を入れない
2. 業務Vaultは公開できる前提の文章に寄せる
3. 認証ファイルは別保管
4. ノート命名規則（例: YYMMDD_タイトル）
5. タグ項目（オーナー、ステータス、ソース）
6. フォルダ構成（00_Inbox, 10_Projects, 90_Archive）

**先にルール → 後にCLI運用。この順番が大事。**

## Claude Code Desktop の権限スキップ（--dangerously-skip-permissions）

### 何ができる
- 全ての確認プロンプトをスキップ → 自律動作モード

### 危険性
- ファイル削除、機密情報の読み取り、意図しない外部通信が確認なしで進む

### 使う条件（全部満たすこと）
1. ☐ コンテナなどの隔離環境で動かす
2. ☐ 読み取り専用マウントにする
3. ☐ 本番環境は使わない
4. ☐ ネットワークを制限する
5. ☐ 作業ログを保存する
6. ☐ 作業対象ディレクトリを固定する
7. ☐ 7項目チェック全部通ってから使う

> 「自動運転モードはテストコース内だけ。公道には出さない。」

## その他の小ネタ

### マルチエージェント運用（9人AIチーム事例）
- スキャルピングリサーチャー×3、リソースモニター×1、バグハンター×1、最適化担当
- 設計の骨格:
  1. 共通前提ドキュメント（目的・制約・データ定義）を1枚に
  2. 役割ごとの入出力・成果物の形式を固定
  3. 統合役（最終判断 + 差分整理）を置く
- **注意**: 誤った仮説が高速増殖する → 検証指標を定量的に固定
