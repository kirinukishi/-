# 出力トークン上限エラーの対処法

## 発生するエラー

```
API Error: Claude's response exceeded the 32000 output token maximum
```

大きなファイル（HTML レポートなど）を Write ツールで一括生成しようとすると発生する。

## 原因

Claude Code のデフォルト出力トークン上限は **32,000トークン**。
長いHTMLやJSONを一度に書こうとするとこの上限を超える。

## 対処法

### 方法1: 分割して書く（推奨）

一括生成ではなく、段階的にファイルを構築する。

1. まずファイルの骨組み（HTML構造）だけ Write で作成
2. セクションごとに Edit で中身を追記
3. 最後に仕上げの Edit

**メリット**: 環境変数の変更不要。途中経過も確認できる。

### 方法2: 環境変数で上限を引き上げる

```bash
export CLAUDE_CODE_MAX_OUTPUT_TOKENS=128000
```

設定後に Claude Code を再起動する必要がある。

**注意**: トークン数が増えるとコストも増加する。

### 方法3: 外部ファイルを活用

- データ部分を別ファイル（JSON/CSV）に分離
- HTMLからそのデータを読み込む構造にする
- Claude には小さなファイルを複数回に分けて生成させる

## 学び

- 「別ウィンドウを開く必要はない」— 同じセッションで分割すれば対処可能
- 大きなファイルは最初から分割戦略で臨む
- 横断パターン「原則5: 小さく始めて段階的に」が適用できる場面
