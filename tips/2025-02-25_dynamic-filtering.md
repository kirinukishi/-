# Claudeの動的フィルタリング（Web検索の強化）

ソース: https://www.youtube.com/watch?v=vmth_nSQByA

## 概要

2026年2月17日にAnthropicが発表。精度11%向上 + コスト24%削減を同時達成。

## 従来の問題

- 検索結果のHTMLを丸ごとコンテキストに突っ込んでいた
- 10ページ分読み込んでも本当に必要な情報は1割
- 残り9割のゴミにもトークン代がかかる
- ノイズが増えるとモデルが重要な情報を見逃す

## 新方式: 動的フィルタリング

1. 検索結果を受け取る
2. **Claudeが自動でPythonコードを生成**（スクレイパー）
3. 「技術ドキュメントだから要る」「広告ページだから要らない」を判定
4. 必要なデータだけコンテキストに入れる
5. 不要なデータはコンテキスト到達前に捨てる → 無駄トークンゼロ

## プログラマティックツールコーリング

- 従来: ツール呼び出し → 結果をClaudeに返す → 次のツール呼び出し（19往復以上）
- 新方式: Claudeがワークフロー全体をオーケストレートするPythonスクリプトを書く → **1回の実行に集約**
- トークン使用量37%削減（43,588 → 27,297トークン）

## API での使い方

```

```

### Python SDK
```python

```

## 向いているケース

- 技術ドキュメント検索（複数ページ横断）
- 文献レビュー・競争分析
- 3つ以上の依存するツール呼び出しがあるワークフロー
- 大量データを集約して結果だけ欲しい場合

## 向かないケース

- 単純な1回検索（「今日の天気は？」）
- コード生成のオーバーヘッドがあるのでシンプルな検索は逆に遅くなる

## 同時にGA化された機能

- **ツール発見機能**: 使えるツールを自動発見（MCP環境で便利）
