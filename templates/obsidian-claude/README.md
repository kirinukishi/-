# Obsidian + Claude Code 連携テンプレート

Obsidian 1.12+ のCLI機能を使って、Claude Code と Obsidian を連携させるための設定テンプレート。

## 使い方

1. このフォルダの中身を自分のObsidian Vault にコピー
2. `_templates/` フォルダがテンプレート置き場
3. フォルダ構成に従ってノートを配置
4. Claude Code から CLI 経由で操作

## セキュリティ3原則（先に決める）

1. 個人Vaultには秘密を入れない
2. 業務Vaultは公開できる前提の文章に寄せる
3. 認証ファイル（.env, credentials）は別保管
